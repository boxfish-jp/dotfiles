## 概要
- todo.orgファイルのタスク一覧をステータス付きで表示する
- タスクの状態をDONE/DEVELOPING/TODO/キャンセルに切り替える
- 指定カテゴリに新しいタスクを追加する
- 既存タスクを削除する
- プロジェクトルートからtodo.orgファイルを検索する

## 使い方
ユーザーがtodo.orgの管理を依頼した場合、まずこのスキルをロードしてから作業する。

## ファイル検索
- プロジェクトルートと直下のサブディレクトリから`todo.org`を検索する
- 複数見つかった場合は、ユーザーに編集対象を選択させる

## org-modeの規則
- 見出しのレベル:
  - `*` = カテゴリ（トップレベル）
  - `**` = タスクグループ
  - `***` = 個別タスク
- タスクの状態キーワード（`***`の後に記載）:
  - `DONE` = 完了
  - `DEVELOPING` = 進行中
  - `TODO` = 予定
  - キーワードなし = 未着手
- `CLOSED:` タイムスタンプは`DONE`の後に記載（形式: `[YYYY-MM-DD 曜日 HH:MM]`、`date`コマンドで現在時刻を取得する）
- タスクは親見出しの下にスペースでインデントする

## 操作内容

### 一覧表示
- todo.orgファイルを読み込む
- ステータス別にタスクを分類して表示する

### 状態変更
- 対象タスクを名前で検索する
- 現在の状態キーワードを新しいものに置き換える
- DONEに変更する場合は`date`コマンドで現在時刻を取得し`CLOSED:`タイムスタンプを追加する

### タスク追加
- 親見出しを見つける
- タスク名を含む新しい`***`見出しを挿入する
- デフォルトの状態はTODO（またはキーワードなし）

### タスク削除
- 対象タスクを名前で検索する
- `***`見出し行と子要素を全て削除する
