# 個人設定

## Web 検索

- 外部情報の収集には Exa の MCP ツール（`mcp__exa__*`）を使う。組み込みの `web_search` は使わない。
- ページ本文の取得も Exa の MCP ツールを優先し、`web_fetch` は Exa 側で取得できない場合だけ使う。
- Exa のツールが一覧に無い場合は、代わりに `web_search` を使わず、検索手段が無いことを報告する。

## サブエージェント

- コードの実装は `subagent_fork`（メインセッションのコンテキストを引き継ぐサブエージェント）に委任する。テストコードの実装・テストコードの検証・動作検証もサブエージェントに委任してよい。
- コードの実装が終わったら、必ずレビューを行う。実装したサブエージェント自身の自己レビューで済ませない。
- ドキュメントの編集だけなら、レビューは不要。
- レビューは `subagent`（コンテキストを引き継がないサブエージェント）に `review` スキルを読み込ませて行う。状態を持つクラス・モジュールが対象なら `state-reduction-review` も読み込ませ、削減候補を分類させる。実装者と同じ会話を見せないことで、実装の前提をそのまま受け入れずに差分を見直せる。
- レビューの対象範囲は、依頼する側が `review-range` スキルに従って決める。コミットしていないファイルを対象とし、今回の編集以外の未コミット変更が混ざる場合は除く部分を明示して渡す。
